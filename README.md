# Mohamed Alagamy — Static Portfolio

Static multi-page portfolio using HTML, CSS, JavaScript, Bootstrap 5 and Tailwind CSS.

Pages: Home, About, Skills, Projects, Contact.

Replace `images/profile-placeholder.svg` with your photo and `images/projects/project-01-placeholder.svg` with your real project screenshot.

To add a future project, copy the commented template in `projects.html`, then change only the image, live URL, project name and alt text. The CSS grid is already responsive: 3 columns on desktop, 2 on tablet, 1 on mobile.

No React, Vite, Node.js or build step is required. It can be hosted directly as static files.
